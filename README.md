# James Arnold - Integration, Flask and Frontend Contribution

This branch contains the files directly attributable to my specialist contribution to the SD205 Fake News Detection project.

The complete end-to-end application is available on the `main` branch.

## Contribution Scope

My work covered:

- Flask application-factory integration
- HTTP routes and API contracts
- Request validation
- Structured success and error responses
- Model-service lifecycle
- Final pipeline SHA-256 verification
- Class and probability mapping
- Backend-to-frontend integration
- Model-health reporting
- Integrated Dark Glass frontend
- HTML templates
- CSS and JavaScript
- Confidence-threshold auditing
- Three-state interpretation policy
- Runtime, Flask and frontend automated testing

## Contribution Boundary

This branch intentionally excludes the main machine-learning development files:

- preprocessing.py
- dataset_preparation.py
- model_experimentation.py
- final_model_evaluation.py
- split_manifest.csv
- Jupyter machine-learning notebooks
- final trained model artefacts

Those files form part of the complete shared application on `main` and represent the machine-learning specialist area.

This branch is maintained as individual-contribution evidence. It is not intended to operate independently as the complete MVP because the integration layer depends on the shared machine-learning pipeline and final model artefacts.

Use the `main` branch to install, test and run the complete application.
